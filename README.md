# Herizon Circle Frontend

This is the frontend application for **Team Herizon-Circle**, developed with **React** and **Vite** as part of our project.

## Tech Stack

* React
* Vite
* JavaScript (SWC)
* React Router DOM
* ESLint

## Getting Started

1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the application in your browser at:

```text
http://localhost:5173
```

## Available Scripts

```bash
npm run dev      # Start development server
npm run build    # Build for production
npm run preview  # Preview production build
npm run lint     # Run ESLint
```
